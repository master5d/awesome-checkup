# The README's install command pointed to a repository that did not exist

A promising tool was close to adoption on the strength of its post and README. Checking three concrete claims against the repository found: the install command referenced a repository that did not exist, a "no telemetry" claim was contradicted by an analytics package in the dependencies, and a headline benchmark omitted the metric where the tool was worse. Now 2–3 claims are checked against the code before any adoption decision.
