# AGENTS.md — awesome-checkup

Файл — для агентов в рабочей копии владельца. Внешним контрибьюторам — `CONTRIBUTING.md`.

Общий контракт лаборатории владельца действует и в этом репо (Codex читает AGENTS.md
от корня своего git-репо, поэтому главное повторено здесь). Самое критичное, сжато:

- **LLM — только через гейтвей лаборатории:** pool-алиасы; никаких сырых имён моделей,
  провайдерских SDK и ключей.
- **Git — поимённо:** `git add <файл>`, не `-A` / `.`; перед коммитом `git status` (коммит берёт
  весь индекс); `reset --hard` / `push --force` / `checkout --` — только по просьбе владельца.
- **Секреты** — не в argv, URL, на экране и в логах; живут в env-файлах.
- **Процессы снимать только по PID**, никогда по имени.
- **Честные exit-коды:** FAIL — значит ненулевой код; статус пайпом не красть.
- **Файлы — UTF-8 без BOM** (голый `>` в Windows PowerShell пишет UTF-16LE).
- **Таймауты на всей сети.**

## Этот репо

- Репо публичный: никаких личных данных, хостов, путей и внутренних имён проектов
  (в том числе в `scars/`).
- npm-workspace: CLI в `packages/cli` (TypeScript, tsup, Vitest).
- Тесты: `npm test`; типы: `npm run typecheck`; сборка: `npm run build`.
- `README.md` и `checklists/*.md` генерируются: правка — в `checklists/*.yaml`, затем
  `npm run render` (`npm run render:check` — сверка). Правила пунктов — `CONTRIBUTING.md`.
